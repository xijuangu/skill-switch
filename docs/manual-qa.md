# MVP 手工验收清单

## 技能

- 扫描后，技能行显示 source 类型、source 数量和已部署工具。
- “安装”默认打开 GitHub 安装；“添加本地”直接打开本地目录页。
- 多 source 冲突时，部署和查看 SKILL.md 都要求选择具体 source。

## 部署与工具

- 多路径工具的部署框列出每个实际路径。
- external skill 覆盖前显示目标路径和备份说明；取消后磁盘不变。
- 删除目标后点击“重新部署”会恢复目标。
- 修改 copy 目标、替换链接、删除 source 时显示对应异常状态。
- 禁用工具不出现在“工具”页，但仍可在“设置”页重新启用。

## 备份

- 恢复已有目标前创建 safety-net。
- 保留数设为 1 时仍能完成恢复。
- 删除和恢复只作用于列表中的备份。

## 构建

- `npm run verify` 通过。
- `npm run dev` 能启动应用。
- 当前平台的 `npm run package:*` 能生成安装产物。
