# skill-switch v1.0.0

## 中文发布说明

skill-switch 是一个本地桌面应用，让你在一个地方安装、整理并部署你的 AI 编程 Skills。它支持从 GitHub、ZIP 包或本地目录安装 Skill，通过整理（Consolidation）建立权威版本，再以 symlink 或 copy 部署到 TRAE、Codex、Claude Code、Agents、Gemini CLI 等多个 AI 编程工具。

### 支持平台

- **macOS**：Apple Silicon 优先的 DMG 安装包（Intel Mac 可运行但独立 DMG 不作为 v1.0 阻塞项）
- **Windows**：x64 NSIS 安装包
- **Linux**：x64 AppImage 与 DEB（DEB 正常生成时一并发布）

### 未签名与未公证状态

skill-switch v1.0 的安装包**未经过代码签名与公证**。首次启动时可能遇到系统警告，这是正常现象，不代表安装失败：

- **macOS Gatekeeper**：双击 .dmg 安装后，首次启动 skill-switch 时 Gatekeeper 可能提示「无法验证开发者」。右键点击应用图标选择「打开」，在弹窗中再次选择「打开」即可放行。
- **Windows SmartScreen**：运行 NSIS 安装包时，SmartScreen 可能提示「Windows 已保护你的电脑」。点击「更多信息」后选择「仍要运行」继续安装。

### 联网边界

skill-switch 是**本地优先**应用：

- 仅在用户主动从 GitHub 安装 Skill 时发起 HTTPS 请求到 `github.com` 与 `raw.githubusercontent.com`
- 不上传任何本地内容到外部服务器
- 无账号、无遥测、无后台服务
- 所有 Skill 整理、部署、备份和恢复操作均在本地完成

### 已知限制

- 不提供自动更新；新版本需手动下载替换
- macOS Intel 独立 DMG、SHA256SUMS.txt 校验文件、代码签名与公证不在 v1.0 范围
- 不提供 i18n，界面与文档以中文为主、英文为辅
- 外部链接仅允许 HTTPS 协议且限定在 GitHub 域白名单内

### 核心能力

- **技能页**：扫描、安装、批量操作、整理（建立权威 Source）、部署到多工具
- **工具页**：工具启用、发现目录管理、部署关系与外部订阅接管
- **恢复页**：来源归档与备份合并为两个标签；优先展示可恢复状态与建议动作，技术详情折叠
- **设置页**：权威源码库、备份保留、平台能力与版本信息

### 部署语义

所有新部署默认请求 symlink，使多个工具共享同一权威 Skill 版本；当平台不支持 symlink 时显式降级为 junction 或 copy，不会静默切换。部署保留 Path-free Mutation 边界与一次性确认。

## English Summary

- **Local-first desktop app** to install, consolidate, and deploy AI coding Skills across TRAE, Codex, Claude Code, Agents, Gemini CLI and more; HTTPS only to github.com when installing from GitHub, no telemetry or accounts.
- **Cross-platform installers**: macOS DMG (Apple Silicon priority), Windows x64 NSIS, Linux x64 AppImage + DEB; apps are **unsigned and notarized**, see Gatekeeper/SmartScreen bypass instructions in README.
- **Unified deploy matrix**: single-item and post-install deployments share the same multi-tool matrix with symlink-by-default and explicit downgrade confirmation.
- **Information architecture**: top-level navigation fixed to Skills / Tools / Recovery / Settings; source archive and backups merged into Recovery tabs; technical details foldable.
- **Hardened Electron shell**: renderer sandbox enabled, context isolation preserved, only HTTPS external links to a GitHub domain allowlist are forwarded to the system browser.
