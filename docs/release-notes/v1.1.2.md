# skill-switch v1.1.2

## 中文发布说明

v1.1.2 解决了「从注册表移除的 Skill 重新扫描后复活」的问题：移除时可把来源目录登记进忽略名单，扫描不再登记它们。批量操作对话框也做了一轮体验改进。

### 支持平台

- **macOS**：Apple Silicon（arm64）DMG 安装包
- **Windows**：x64 NSIS 安装包
- **Linux**：x64 AppImage 与 DEB（DEB 正常生成时一并发布）

### 未签名与未公证状态

skill-switch 的安装包**未经过代码签名与公证**。首次启动时可能遇到系统警告，这是正常现象，不代表安装失败：

- **macOS Gatekeeper**：双击 .dmg 安装后，首次启动 skill-switch 时 Gatekeeper 可能提示「无法验证开发者」。右键点击应用图标选择「打开」，在弹窗中再次选择「打开」即可放行。
  - **macOS Sequoia (15+) 「已损坏」提示**：浏览器下载的未签名应用可能直接显示「已损坏」，右键打开无效。终端执行 `xattr -dr com.apple.quarantine /Applications/skill-switch.app` 移除隔离属性后即可正常打开；或用 `curl -L -o skill-switch.dmg <下载链接>` 从终端下载（不附加隔离属性）。
- **Windows SmartScreen**：运行 NSIS 安装包时，SmartScreen 可能提示「Windows 已保护你的电脑」。点击「更多信息」后选择「仍要运行」继续安装。

### 联网边界

skill-switch 是**本地优先**应用：

- 仅在用户主动从 GitHub 安装 Skill，或点击"检查更新"读取 GitHub Latest Release 元数据时联网
- 不上传任何本地内容到外部服务器
- 无账号、无遥测、无后台服务
- 所有 Skill 整理、部署、备份和恢复操作均在本地完成

### 已知限制

- 不自动下载或安装更新；"检查更新"发现新版本时只打开 GitHub Release 页面，仍需手动下载替换
- macOS Intel 独立 DMG、SHA256SUMS.txt 校验文件、代码签名与公证不在当前范围
- 不提供 i18n，界面与文档以中文为主、英文为辅
- 外部链接仅允许 HTTPS 协议且限定在 GitHub 域白名单内

### v1.1.2 变更

**忽略来源目录（解决 v1.1.1 已知限制）**：
从注册表移除 Skill 时，对话框默认勾选「忽略这些来源目录，扫描不再登记」。勾选后，权威源码库之外的来源路径进入忽略名单，之后的扫描（启动扫描与手动扫描）不再把这些目录登记回来——被移除的 Skill 不再确定性复活。忽略按路径而非按名称生效（ADR 0007），不会误伤同名 Skill；「恢复」页新增「忽略目录」标签，可查看并逐条解除；任何显式登记同一路径的操作也会自动解除对应忽略。单个与批量移除入口均支持。

**批量操作体验改进**：
- 批量模式下点击 Skill 行，勾选的同时右侧详情同步跳转（点复选框本身仍只切换勾选）。
- 「全选当前」旁新增「清空」，一键取消全部勾选。
- 部署 Tab 中已有受管部署的项目带「已部署」标记；部署与取消部署的组头右侧展示「x个已部署」汇总。
- 取消部署 Tab 改为与部署一致的分组样式：按工具分组、组头三态开关、默认折叠，取代原「目标工具」筛选下拉。

**文档同步**：
用户指南「取消部署与从注册表移除」「忽略名单」两节、CONTEXT.md 领域语言与 ADR 0007 同步更新。

## English Summary

- **Ignored source paths (resolves the v1.1.1 known limitation)**: removing a skill from the registry now offers a default-on "ignore these source directories" option. Ignored paths are no longer re-registered by scans, so removed skills stop deterministically resurrecting. Ignoring is path-based, not name-based (ADR 0007); a new "忽略目录" tab on the Recovery page lists and un-ignores entries, and any explicit registration of a path lifts its ignore automatically.
- **Bulk actions UX**: row click in bulk mode now navigates the detail pane while toggling; a "清空" button pairs with select-all; deploy items already under managed deployment carry an "已部署" badge and group headers show deployed counts; the undeploy tab adopts the deploy tab's grouped, tri-state, collapsed-by-default style.
- **Docs**: user guide sections on registry removal and the ignore list, domain language, and ADR 0007 updated.
- **Cross-platform installers**: macOS arm64 DMG, Windows x64 NSIS, Linux x64 AppImage + DEB; apps are **unsigned and unnotarized**.
