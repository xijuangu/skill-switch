# skill-switch v1.1.1

## 中文发布说明

v1.1.1 重做了批量操作对话框中部署项的选择方式：按目标工具分组选择，免除「逐对取消勾选」的高成本操作。

### 支持平台

- **macOS**：Apple Silicon（arm64）DMG 安装包
- **Windows**：x64 NSIS 安装包
- **Linux**：x64 AppImage 与 DEB（DEB 正常生成时一并发布）

### 未签名与未公证状态

skill-switch 的安装包**未经过代码签名与公证**。首次启动时可能遇到系统警告，这是正常现象，不代表安装失败：

- **macOS Gatekeeper**：双击 .dmg 安装后，首次启动 skill-switch 时 Gatekeeper 可能提示「无法验证开发者」。右键点击应用图标选择「打开」，在弹窗中再次选择「打开」即可放行。
  - **macOS Sequoia (15+) 「已损坏」提示**：浏览器下载的未签名应用可能直接显示「已损坏」，右键打开无效。终端执行 `xattr -dr com.apple.quarantine /Applications/skill-switch.app` 移除隔离属性后即可正常打开；或用 `curl -L -o skill-switch.dmg <下载链接>` 从终端下载（不附加隔离属性）。
- **Windows SmartScreen**：运行 NSIS 安装包时，SmartScreen 可能提示「Windows 已保护你的电脑」。点击「更多信息」后选择「仍要运行」继续安装。

### 联网边界

skill-switch 是**本地优先**应用：

- 仅在用户主动从 GitHub 安装 Skill，或点击"检查更新"读取 GitHub Latest Release 元数据时联网
- 不上传任何本地内容到外部服务器
- 无账号、无遥测、无后台服务
- 所有 Skill 整理、部署、备份和恢复操作均在本地完成

### 已知限制

- 不自动下载或安装更新；"检查更新"发现新版本时只打开 GitHub Release 页面，仍需手动下载替换
- macOS Intel 独立 DMG、SHA256SUMS.txt 校验文件、代码签名与公证不在当前范围
- 不提供 i18n，界面与文档以中文为主、英文为辅
- 外部链接仅允许 HTTPS 协议且限定在 GitHub 域白名单内
- 从注册表移除的 Skill 若仍残留于工具目录或候选来源目录中，重新扫描会被再次登记（忽略名单机制规划于后续版本）

### v1.1.1 变更

**批量部署按目标工具分组选择**：
批量操作对话框的部署项不再扁平铺开，而是按 Discovery Target 分组展示，每组组头提供三态全选开关（部分勾选时显示半选态）。把 N 个 Skill 只部署到某一个工具，从原来的 N×(M−1) 次逐对取消变为一次组头点击；组内仍保留逐项微调。

**部署与取消部署默认不选**：
两个 Tab 打开时均为空选择，由用户显式选出目标后才能提交，避免破坏性更大的默认全选被误提交。未勾选任何项时执行按钮保持禁用并给出提示。

**文档同步**：
用户指南「批量操作」一节同步更新为新交互。

## English Summary

- **Bulk deploy selection grouped by Discovery Target**: deploy items in the bulk actions dialog are grouped per target tool, each with a tri-state select-all header switch. Deploying N skills to a single tool now takes one group-header click instead of N×(M−1) per-pair unchecks; per-item fine-tuning is preserved.
- **Deploy and undeploy tabs open with an empty selection**: targets must be explicitly chosen before submitting, replacing the riskier default-select-all; the confirm button stays disabled with a hint until something is selected.
- **Docs**: the bulk operations section of the user guide updated to match the new interaction.
- **Cross-platform installers**: macOS arm64 DMG, Windows x64 NSIS, Linux x64 AppImage + DEB; apps are **unsigned and unnotarized**.
