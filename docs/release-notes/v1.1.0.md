# skill-switch v1.1.0

## 中文发布说明

v1.1.0 在 v1.0.0 基础上改进了整理（Consolidation）与工具页批量操作的 UX，并修复了外部 skill 读模型一致性问题。

### 支持平台

- **macOS**：Apple Silicon（arm64）DMG 安装包
- **Windows**：x64 NSIS 安装包
- **Linux**：x64 AppImage 与 DEB（DEB 正常生成时一并发布）

### 未签名与未公证状态

skill-switch 的安装包**未经过代码签名与公证**。首次启动时可能遇到系统警告，这是正常现象，不代表安装失败：

- **macOS Gatekeeper**：双击 .dmg 安装后，首次启动 skill-switch 时 Gatekeeper 可能提示「无法验证开发者」。右键点击应用图标选择「打开」，在弹窗中再次选择「打开」即可放行。
  - **macOS Sequoia (15+) 「已损坏」提示**：浏览器下载的未签名应用可能直接显示「已损坏」，右键打开无效。终端执行 `xattr -dr com.apple.quarantine /Applications/skill-switch.app` 移除隔离属性后即可正常打开；或用 `curl -L -o skill-switch.dmg <下载链接>` 从终端下载（不附加隔离属性）。
- **Windows SmartScreen**：运行 NSIS 安装包时，SmartScreen 可能提示「Windows 已保护你的电脑」。点击「更多信息」后选择「仍要运行」继续安装。

### 联网边界

skill-switch 是**本地优先**应用：

- 仅在用户主动从 GitHub 安装 Skill，或点击"检查更新"读取 GitHub Latest Release 元数据时联网
- 不上传任何本地内容到外部服务器
- 无账号、无遥测、无后台服务
- 所有 Skill 整理、部署、备份和恢复操作均在本地完成

### 已知限制

- 不自动下载或安装更新；"检查更新"发现新版本时只打开 GitHub Release 页面，仍需手动下载替换
- macOS Intel 独立 DMG、SHA256SUMS.txt 校验文件、代码签名与公证不在当前范围
- 不提供 i18n，界面与文档以中文为主、英文为辅
- 外部链接仅允许 HTTPS 协议且限定在 GitHub 域白名单内

### v1.1.0 变更

**整理时原地迁移受管部署（#123 #124，ADR 0005）**：
整理替换权威 Canonical 内容时，批次已锁定的受管部署被原子迁移到新权威路径——symlink/junction 重定向，copy 按新权威内容重新部署。这修正了 ADR 0004 中"整理与 Deployment 分离"的措辞：整理仍不创建新部署，但不留下清单与文件系统漂移。

**卡片式整理预览与批量操作对话框（#125 #126）**：
整理预览改为按 skill 分组的卡片式展示；整理 Tab 整合到批量操作对话框中，与部署关系批量操作共用入口。

**工具页分组多选批量操作（#127）**：
工具页按受管部署 / 外部订阅 / 外部 skill 三组各自多选，每组带全选与内联批量操作栏。受管部署可批量取消部署或重新部署，外部订阅可批量接管。注：外部 skill 分组的多选能力在 ADR 0006 中移除，仅受管部署 / 外部订阅两组支持多选。

**外部 skill 读模型一致性修复（ADR 0006）**：
`readToolDrifts` 新增 `registered-candidate` drift kind，跨表查询 `skill_sources` 表——已被 scan 登记为候选来源的外部 skill 在工具页显示"已登记候选"而非"未管理"，与技能页读模型一致。同时移除 ToolsPage 冗余的"登记候选"按钮（与 SkillsPage 扫描按钮重复调用 `scanAllTools`），扫描统一走 SkillsPage。同时移除 external 分组的多选 checkbox（按钮移除后多选无操作可触发）。

## English Summary

- **Consolidation redirects managed deployments in place (#123 #124, ADR 0005)**: symlink/junction managed deployments are redirected to the new canonical path during consolidation; copy deployments are redeployed with new canonical content. Consolidation still creates no new deployments, but no longer leaves manifest/filesystem drift on locked targets.
- **Card-style consolidation preview and integrated batch dialog (#125 #126)**: consolidation preview grouped by skill as cards; consolidation tab merged into the bulk actions dialog.
- **Tools page group multi-select with bulk operations (#127)**: managed / observed / external groups each support select-all and inline bulk actions (bulk undeploy, bulk redeploy, bulk adopt). Note: the external group's multi-select capability was removed in ADR 0006; only the managed and observed groups support multi-select.
- **External skill read model consistency fix (ADR 0006)**: new `registered-candidate` drift kind; `readToolDrifts` cross-checks the `skill_sources` table so scan-registered external skills show "已登记候选" on the Tools page, consistent with the Skills page. Redundant ToolsPage "登记候选" button removed (it duplicated the Skills page scan button with no scope effect); the external group's multi-select checkbox was also removed (with the button gone, multi-select had no action to trigger); scanning is now triggered only at startup or via the Skills page.
- **Cross-platform installers**: macOS arm64 DMG, Windows x64 NSIS, Linux x64 AppImage + DEB; apps are **unsigned and unnotarized**.
